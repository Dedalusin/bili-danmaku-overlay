# B站直播弹幕悬浮窗

打游戏时听 B 站直播杂谈,也能看到实时弹幕——透明的弹幕悬浮窗,悬浮在游戏画面上方。

## 功能

- **实时弹幕**:WSS 直连 B 站弹幕服务器,60fps 渲染,像素级透明窗口
- **可交互区域**:鼠标移到弹幕区域显示边界,可拖动位置、拖右下角缩放大小
- **控制台**:主播名下拉切换直播间、添加/删除直播间(自动抓取主播名)、显示/隐藏、速度/字号/密度调节
- **配置持久化**:直播间列表、滚动区域位置大小、各项参数下次启动自动沿用
- **点击穿透 + 置顶**:不挡游戏操作、不被其他窗口覆盖(游戏需无边框窗口化)

## 使用

```
pip install pygame websocket-client brotli
python bili_overlay_v2.py            # 启动, 沿用上次配置
python bili_overlay_v2.py 1727076670 # 启动并切换到指定直播间
```

## 说明

- 弹幕协议:游客身份 + wbi 签名 + WebSocket,2026-08 验证可用
- `config.json` 为本地配置(不入库):直播间列表、当前房间、速度/字号/密度、滚动区域位置大小
- 全屏独占模式的游戏会遮挡一切 overlay,请使用无边框窗口化
